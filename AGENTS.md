# Git Workflow Rule

After completing a feature or a logical unit of work (e.g. resolving a user's request, doing UI improvements, fixing a bug), you MUST commit the changes to version control.
Do not leave uncommitted changes hanging when switching to a new feature or ending your turn if the current task is complete.
If you create patches or diffs in the artifacts directory to test things, always make sure to apply and commit them to the repository before moving on to unrelated tasks.
